## Status and error message contract
| Status | Expected user guidance | Operator action |
|---|---|---|
| 200/201 | Specific completed action; don't call a simulator transfer a real payment | Audit mutation and source of truth |
| 400 / 415 | Invalid input, JSON shape, media type; correct field | No raw SQL or stack details |
| 401 | Sign in again if session expired | Inspect cookie/session expiry safely |
| 403 | Not permitted or CSRF expired; never reveal other user records | Verify actor/resource scope |
| 404 | Resource not found / inaccessible | Confirm ID and access |
| 409 | Explain blocked state/duplicate submission | Check current order/proof/job/refund stage |
| 413 / 429 | File too big / try later | Review abuse; in-memory throttling not production-ready |
| 500 / 502 / 503 | Safe message and request reference, no false success | Correlate logs/provider/DB error |

## Execution evidence and limitations
GitHub Actions quality gate runs Node unit/API/webhook/security/negative tests, `schema:preflight`, and Playwright Chromium visual smoke on PRs and main. The browser suite uses **mocked API responses** and evaluates sizes 375px, 390px, 768px and 1440px. Inspect the linked workflow's actual conclusion before marking it passed. A reviewer must additionally run deployed staging flows, payment/provider failure/retry, concurrency and idempotency tests, persistent database restore, axe/screen-reader checks, actual artwork proof, real financial and tax acceptance, physical manufacturing/QC and carrier tests. Capture a BRD-to-test coverage/signoff matrix.

## Go / no-go
**Go:** isolated customer-supervised exploratory UAT with disposable data, no confidential artwork, no real payment and clearly labeled test rates/simulated transactions.

**No-go:** actual production launch or full BRD acceptance while SQLite is experimental, pricing and renderings are sample-only, secure artwork and PDF proofs are missing, email reset/MFA and tenancy controls are not certified, Razorpay and courier flows are unverified, and production tax invoice/reconciliation is absent.

Track build SHA, environment URL, CI run ID, defects with severity/repro, fix SHA, rerun evidence, roles and final client signoff; never include secrets or PII.
